# Security

These patches run inside Sync with your Reddit login, so security problems matter. If you find one, please don't
open a public issue: report it privately through
[Report a vulnerability](https://github.com/Krokette/revanced-sync-fixes/security/advisories/new) instead.

Only the latest release is supported. Install it through the Manager link in the [README](README.md#install), or
from [Releases](https://github.com/Krokette/revanced-sync-fixes/releases) on this repository: other copies of the
bundle are not from this project.
